# Product Requirements

## 현재 기준

- [Orbit 개인 업무 연속성 PRD](prd-orbit-work-continuity.md)
- 기존 [Orbit 개인 업무 연속성 Spec](spec-orbit-work-continuity.md)은 링크 호환성을 위해 현재 위치에 유지하며, 새 Spec은 [specs/](../specs/README.md)에 작성한다.

## 역할 구분

- PRD: 사용자 문제, 목표·비목표, 범위, 성공 지표와 수용기준을 소유한다.
- Spec: [specs/](../specs/README.md)에서 사용자 흐름, 상태, 데이터/API 계약과 테스트 시나리오를 소유한다.
- Design Document: [design-documents/](../design-documents/README.md)에서 구현 세부, migration, rollout과 observability를 소유한다.

새 PRD는 [PRD template](../templates/prd-template.md)에서 시작하고 파일명은 `한글-기능명.md` 형식을 사용한다.
